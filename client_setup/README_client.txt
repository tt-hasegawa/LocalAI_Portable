LocalAI Portable - クライアントPC向け簡単セットアップガイド
==============================================================================

自席PCのブラウザから社内サーバーの LocalAI (VS Code Web) にアクセスする際、
Continue のチャット画面を表示可能にするための設定ツールです。
状況に合わせて以下のいずれか1つをご利用ください。

------------------------------------------------------------------------------
【方法 A】一番手軽：信頼済みサイト自動登録（HTTP利用時）★推奨
------------------------------------------------------------------------------
1. `enable_trusted_site.bat` をダブルクリックして実行します（管理者権限不要）。
2. プロンプトに接続先URL（例: http://omecvsv01386:8000）を入力し、Enterを押します。
3. Chrome または Edge を再起動して接続してください。
※ chrome://flags などの面倒な手動入力が不要になります。

------------------------------------------------------------------------------
【方法 B】サーバーが HTTPS（SSL）モードの場合
------------------------------------------------------------------------------
- 社内CA証明書（Active Directory等）が使われている場合:
  クライアント側の設定は一切不要です。ブラウザでそのまま
  https://<サーバー名>:8443/ にアクセスしてください。

- 自己署名証明書（サーバーで自動生成した証明書）の場合:
  1. `cert/LocalAI_Server.cer` をこのフォルダにコピーします。
  2. `install_server_cert.bat` を右クリックして「管理者として実行」します。
  3. 証明書が登録されたら、ブラウザで https://<サーバー名>:8443/ にアクセスします。
     （警告が出ず、緑の鍵マークで安全にアクセスできます）
